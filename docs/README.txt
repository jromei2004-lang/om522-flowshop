OM 522 Fall 2026 team decision-tool project (revised October 7, 2026)
===========================================

Start with team-project-guide.pdf. Its second box lists what changed in this revision, which
removes work rather than adding it. The guide defines what every team builds, the three
milestones, the grading rubric, and the run the instructor performs on each final submission.

Each option has a brief, option-1-brief.pdf through option-7-brief.pdf, giving that option's
decision, input files, required constraints, required output, measures, rule to beat, suggested
reading, stress-test input, and scope boundary.

Each option also has one data ZIP whose name begins with its option number. Download the revised
ZIP for your option, because the data dropped unused files and columns (every other value is
unchanged). That ZIP contains the option's brief again, a data dictionary for its columns, five
instance directories, and a worked example that applies the option's rule to beat to the
smallest instance.

Deadlines are in the course schedule and on Blackboard, not in these files.
